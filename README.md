# Probabilistic Data Structures Lab

A collection of implementations, experiments, and analyses of probabilistic data structures focused on space-efficient computation, approximate querying, and scalable data processing.

This repository was developed as part of exploratory work in advanced data structures and efficient large-scale information processing.

---

# Overview

Probabilistic data structures trade exactness for significant improvements in:

* memory efficiency
* computational scalability
* query speed

These structures are widely used in:

* distributed systems
* databases
* caching systems
* networking
* search engines
* large-scale analytics
* streaming applications

This repository explores the implementation and behaviour of such structures through practical experimentation and analysis.

---

# Implemented / Planned Structures

* Bloom Filter
* Count-Min Sketch
* Cuckoo Hashing

---

# Objectives

* Understand the theoretical foundations of probabilistic data structures
* Analyse memory-performance tradeoffs
* Evaluate false positives and approximation behaviour
* Explore scalable and streaming-oriented data processing techniques
* Compare deterministic vs probabilistic approaches
